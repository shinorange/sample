# テクスチャリング(ドット絵)技法

モデルの印象の半分以上はテクスチャで決まる。同じジオメトリでも塗りで
バニラ級にも素人作にもなる。ここでは Minecraft エンティティ特有の制約と
ドット絵技法をまとめる。

## エンジンの陰影を理解してから塗る

Minecraft は面の向きで自動的に明暗を付ける(概ね 上=100%、北南=80%、
東西=60%、下=50%)。つまり:

- **強い方向性ライティングをテクスチャに焼き込まない**。上面を明るく下面を
  暗く塗り込むとエンジン陰影と二重になり、上面が飛び・下面が潰れる。
- テクスチャに焼き込むのは**素材の陰影**だけ: 関節・付け根の
  アンビエントオクルージョン(1〜2px の暗色)、毛並みの流れ、凹凸の示唆。
- 各面をほぼ同じ明度基調で塗っても、ゲーム内では面の向きで立体感が出る。
  「塗りが平坦すぎるか」はレンダラー(shade 近似入り)や Blockbench で確認。

## パレット設計

- **1 素材 = 4〜6 段階**の限定パレット。バニラの大半がこの範囲
  (クリーパーは緑 5 段 + 黒)。段数が多い=リッチではない。多いと濁る。
- **色相シフト**: 暗い段は単に暗くせず色相を寒色(青紫)へ、明るい段は暖色
  (黄)へ数度ずらす。これがバニラの「生きた色」の正体。
  例(茶色の毛皮): `#8a6543 → 影 #6b4a35(赤紫寄り) → 最暗 #4a3226`
  `→ ハイライト #a5814f(黄寄り)`。
- 彩度は中間段が最も高く、明暗両端で下げる(彩度の山)。
- MOB 全体で**基調色 1 + 副色 1 + アクセント 1** の 3 色構成に収める。
  アクセント(目・発光部・模様)は基調色の補色寄りにすると視線が集まる。
- 既存 MOB と並んで違和感がないか= バニラの彩度レンジ(やや低彩度)に
  収まっているかを確認する。純色 (#ff0000 等) はバニラには存在しない。

## 面ごとの塗り分け手順

1. **ベタ塗り**: 全キューブの全面を素材の中間色で埋める(UV の取り忘れ・
   ずれがこの段階で見える。抜けは validate/render で確認)。
2. **面の基調差**: 腹側を 1 段明るく、背側を 1 段濃く(生物の
   カウンターシェーディング)。エンジン陰影と喧嘩しない範囲で。
3. **AO とエッジ**: パーツの境界・付け根・関節に 1px の影段。キューブの
   輪郭全周を線で囲むのは NG(格子柄になる)。**接地・接合部だけ**。
4. **素材ノイズ**: 下記イディオムで 2〜3 段をランダム散らし。1 面の 10〜30%
   のピクセルだけ触る。全面ノイズは砂嵐になる。
5. **ディテール描画**: 目・鼻・爪・模様・傷。
6. **検証**: `render_geo.py --texture` で全ビュー確認 → ゲーム内/Blockbench。

## 素材別の表現イディオム

- **毛皮**: 毛流れ方向に 1×2〜1×3 の縦長ストローク状に明暗を散らす。
  輪郭の毛先は板ポリ+透過ギザギザ(detail-techniques.md)。
- **鱗**: 2×2 か 3×3 の繰り返しブロックを半段ずらしで敷く(レンガ配列)。
  各鱗の左上 1px を明、右下 1px を暗にすると膨らむ。
- **金属**: 段階を減らし(3 段)、明暗の境界をくっきり。ハイライトは
  エッジに 1px 線で入れる。ノイズを入れないことが金属感になる。
- **骨・角**: 白でなく黄灰色ベース。長手方向に暗線 1 本で「筋」。
- **粘液・スライム**: 大きい明部(スペキュラの塊)を 1 箇所 + 内部に
  気泡の暗点。半透明にするならマテリアル側で(ピクセル半透明は使わない)。
- **岩・古代系**: 大きめの色面ブロック(3〜6px 塊)でゴツゴツを作り、
  ひび 1px 線。ウォーデン/ゴーレム文法。
- **布**: しわを谷 1px 暗線で。端に 1px の縁取り色(ほつれ)。

## 顔・目の描き方

顔は視線が最初に行く場所。ここだけは 1px 単位で詰める。

- **目のサイズ感**: 8×8 顔なら目は 2×2 か 2×3、離し気味(外寄り)に置くと
  Minecraft らしい。1px 目は虫・魚用。大きい目(3×4+)はマスコット向け。
- **構造**: 白目(or 明色)+ 虹彩(アクセント色)+ 瞳(最暗)+
  ハイライト 1px(左上)。4 色 4〜6px で驚くほど表情が出る。
- ハイライトの位置を左右の目で**同じ側**にする(光源の一貫性)。
- 眉・目の上 1px を暗くすると精悍/怒り、下 1px を明るくすると幼く見える。
- 口は基本 1px 線。牙は下顎に 1px 白点 2 個で十分(ジオメトリの牙は
  大型MOB専用)。
- 鼻先は暗色 2×1〜2×2(哺乳類)か、テクスチャ無し(爬虫類・スライム系)。

## 透過・発光・重ね着

- **透過は 2 値**(alpha 0 か 255)。中間アルファはエンティティの標準
  マテリアル(cutout)では機能しない(見えないか不透明になる)。
  半透明の体はマテリアル自体を translucent 系にする(ゴースト・スライム)。
- 板ポリの輪郭切り抜き・重ね着レイヤーの覗き穴は透過で作る
  (detail-techniques.md 参照)。
- **発光(エミッシブ)**: Bedrock はマテリアル `entity_emissive_alpha` 系 +
  アルファチャンネルを発光マスクとして使う方式。Java+OptiFine は
  `テクスチャ名_e.png` を置く方式。発光部は**小面積・高彩度**が効く
  (全身発光は安っぽい。目・模様ラインだけ光らせる)。
- 重ね着殻レイヤーのテクスチャは「透過 70% + 模様 30%」程度に抑えると
  下のレイヤーが生き、立体感が出る。

## プログラムによるテクスチャ生成

Claude がテクスチャを作る場合は PIL で直接ピクセルを打つ。手順:

1. `geo_builder.py` でモデルを組み、`uv_map()` / `uv_report()` で
   **各キューブ・各面の矩形座標を取得**する(座標のハードコード禁止。
   モデル変更で即ズレる)。
2. 面矩形ごとに: ベタ→基調差→AO→ノイズ→ディテールの順で描画する
   関数を作る(`paint_face(img, rect, ...)` の形で再利用)。
3. ノイズは `random.Random(固定シード)` で決定的にする(再現性)。
4. 透過部分は `(0,0,0,0)`。**未使用領域も (0,0,0,0) のまま残す**
   (デバッグ時にUVのはみ出しがすぐ分かる)。
5. `render_geo.py --texture` で全ビューを見て、目・模様の位置ずれ、
   左右 mirror の向き、板ポリの切り抜き形状を確認 → 修正ループ。

references/worked-example/ に、この手順を最初から最後まで実装した
実例スクリプトがある(fennec)。テクスチャ生成コードを書くときは
まずそれを読むこと。
