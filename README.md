# xauforecast — XAUUSD 統計収集 & 1分〜24時間先の確率予測

XAUUSD（金/米ドル）の 1 分足から統計情報を一括で収集し、その統計を**動的に使って**
任意の時点から **1分・5分・15分・30分・1時間・2時間・4時間・8時間・12時間・24時間先** の
値動きを予測するツールです。

## 最初に: 「完全な予測」について

値動きを完全に予測することはできません。金価格の**方向**は統計的にはほぼランダムウォークです
（数分を超えるホライズンでは、方向の予測力は誤差の範囲に収まります）。
一方で、次のものは統計的にかなり正確に予測できます。

| 予測できるもの | 精度の目安 |
|---|---|
| **どのくらい動くか**（ボラティリティ・値幅） | ボラ予測の損失が単純なボラ比で 40〜60% 改善（合成データ検証） |
| **価格がどの範囲に収まるか**（確率区間） | 90% 区間に実際 89〜90% が収まる（較正済み） |
| **±x% に到達する確率**、上と下のどちらに先に到達するか | 予測確率と実際の頻度の差は数ポイント |
| **方向**（上がるか下がるか） | ごく短期（1〜5分、ビッド・アスクの揺らぎ由来）以外は 50% ≒ 予測不能 |

そのためこのツールは、1 つの価格を当てるのではなく**確率分布**（中央値・分位点・上昇確率・
予想高値/安値・到達確率）を出力します。方向モデルは、過去検証で有意な予測力が確認された
ホライズンでだけ自動的に有効になり、それ以外ではドリフト 0 として扱います（見せかけの予測を出さないため）。

## セットアップ

```bash
pip install -r requirements.txt
```

Python 3.10 以降、numpy / pandas / scipy / scikit-learn / requests が必要です。MT5 からリアルタイム取得する場合は
Windows で `pip install MetaTrader5` も入れてください。

## 使い方

### 1. データ取得

Dukascopy の無料ヒストリカルデータ（APIキー不要）を取得します:

```bash
python -m xauforecast fetch --source dukascopy --start 2024-01-01
```

`data/xauusd_m1.csv.gz` に保存されます。再実行すると差分だけ追記します。
Dukascopy のデータは数十分〜1時間ほど遅れて公開されます。

MT4/MT5 のエクスポートや HistData などの手元の CSV を使う場合:

```bash
python -m xauforecast fetch --source csv --path XAUUSD_M1.csv --tz NY+7
```

`--tz` には CSV に入っている時刻のタイムゾーンを指定します。
多くの MT4/MT5 ブローカーのサーバー時間は `NY+7`（夏時間に連動する UTC+2/+3）です。
ほかに `UTC`、`Asia/Tokyo`、`UTC+2` などが使えます。HistData 形式は自動で EST として扱います。

MT5 ターミナルから直接取得する場合（リアルタイム、Windows のみ）:

```bash
python -m xauforecast fetch --source mt5 --start 2024-01-01 --tz NY+7
```

### 2. 一括実行（統計 + 検証 + 学習 + 予測）

```bash
python -m xauforecast all
```

`reports/` に次のファイルが出力されます。

| ファイル | 内容 |
|---|---|
| `stats.md` / `stats.json` | 統計レポート（下記の全項目） |
| `backtest.md` / `backtest.json` | ウォークフォワード検証の結果 |
| `forecast.html` | 予測ページ（ファンチャート、ホライズン別の表、到達確率、予測の根拠、類似局面、検証結果） |
| `forecast.json` | 予測の全データ |
| `features.md` / `feature_ic.csv` | 全特徴量（統計量）のホライズン別の予測力と、モデル各部の採否 |
| `rules.md` / `rules.csv` | トレードルール探索の結果（`rules` コマンド） |

### 3. いつでも予測する

最新足から予測する場合:

```bash
python -m xauforecast forecast
```

過去の任意の時点から予測する場合（その時点までのデータだけで学習し直すので、先読みはありません）:

```bash
python -m xauforecast forecast --at "2025-06-06 12:30"
```

一定間隔で自動更新する場合は次のコマンドです。データ更新 → 必要なら再学習 → 予測 を繰り返します。

```bash
python -m xauforecast live --source mt5 --interval 60
```

`--source` は `mt5`（リアルタイム）、`dukascopy`（遅延あり）、`csv`（自前のフィードで更新される CSV を読み直す）、
`none`（データ更新なし）から選べます。モデルは学習データの末尾から `--refit-hours`（既定 24 時間）を
過ぎると自動で再学習します。ボラ水準・特徴量・季節性は毎回の予測で最新データから計算し直します。

### 4. 個別コマンド

```bash
python -m xauforecast stats --events calendar.csv
```

```bash
python -m xauforecast backtest --folds 4
```

```bash
python -m xauforecast fit
```

```bash
python -m xauforecast synth
```

`stats` は統計だけを計算します。`--events` は省略できます。`backtest` は検証だけ、`fit` は学習だけを行います。
`synth` は動作確認用の合成データを作ります（実際の相場データではありません）。

FOMC の日程（2024〜2026 年）は組み込み済みで、指定しなくても特徴量と統計に使われます。
それ以外の指標や期間は、`--events` で次の形式の CSV を指定してください（組み込みの FOMC と合わせて使われます）。

```
time,name,tz
2025-01-10 08:30,NFP,America/New_York
2025-01-15 08:30,CPI,America/New_York
2025-01-29 14:00,FOMC,America/New_York
```

## 収集する統計情報

`stats.md` / `stats.json` に出力される項目です。

1. **ホライズン別のリターン分布**（1分〜24時間）: σ（bp と $）、平均絶対変動、平均と t 値、上昇・下落・横ばいの比率、
   歪度、超過尖度、Hill 裾指数、Jarque-Bera 検定、±1〜4σ 超えの頻度、0.5%〜99.5% の分位点
2. **スケーリング**: σ(h) ∝ h^H の H（Hurst 指数）、Lo-MacKinlay 分散比検定（不均一分散に頑健な z 値）
3. **自己相関**: 1分・5分・1時間・日次のリターンと絶対リターンの ACF、Ljung-Box 検定、1分足 |r| の長期記憶（〜2日）
4. **季節性**: NY 時間別（ボラ、分散寄与、レンジ、1 時間リターンと t 値、出来高）、毎時の「何分」別、
   曜日別、月別、月末月初効果、セッション別（アジア、ロンドン、NY午前、NY午後）
5. **週内で最もボラが高い時刻**（指標発表時刻などを自動で検出）
6. **時刻イベント**: ロンドン AM/PM フィキシング、COMEX 開場と終了、米指標 8:30 / 10:00、NY 株式開場、
   東京 9:00、上海金開場の前後のボラ倍率と、初動とその後の相関
7. **米雇用統計**（第1金曜 8:30 NY と推定）と、ユーザー指定の指標前後の値動き（1分〜24時間）
8. **ボラティリティ**: 年率ボラの 5 種の推定量（終値、Parkinson、Garman-Klass、Rogers-Satchell、Yang-Zhang）、
   日次実現ボラの分布と現在の分位、ボラのボラ、log RV の自己相関、日次 HAR-RV、
   GJR-GARCH（脱季節化した 5 分足。持続性、半減期、レバレッジ係数）、レバレッジ効果、ATR、日中レンジ
9. **値幅**: ホライズン別の高値−安値レンジ、最大上昇幅・最大下落幅（MFE/MAE）
10. **価格到達確率**（経験値）: ±0.1〜2% に 15分・1時間・4時間・24時間以内に到達する確率と、上と下のどちらが先か
11. **条件付き統計**: 過去リターンの五分位 → 次のリターン（モメンタムか平均回帰か）、RSI 帯別、
    EMA 乖離の五分位別、ボラ局面別の翌日、連続陽線・陰線の後、ラン検定
12. **セッション間の関係**（アジア → ロンドン → NY のリターン相関）
13. **ギャップ**: 週明けと日次再開の窓の分布、24 時間以内に窓が埋まる確率
14. **キリ番**: $10 / $50 / $100 の価格付近で反発するか突破するか（キリ番の中間の価格と比較）
15. **出来高**: ティック出来高と |リターン| の相関、時間帯別の出来高、出来高急増後のボラ
16. **トレンド**: MA20/50/100/200 との乖離と上にいた日の比率、最大ドローダウン、期間別の騰落
17. **過去最大の変動**（1分、1時間、1日）
18. **現在の状況**: 脱季節化ボラ（1時間、4時間、1日、5日）の歴史的な分位、RSI
19. **高度な統計**: BNS ジャンプ検定、実現セミ分散（下方と上方のどちらが翌日のボラを予測するか）、日中モメンタム、
    順列エントロピー、DFA による Hurst 指数、ボラの周期（スペクトル）、1時間足のマルコフ遷移確率と独立性検定、
    ボラ局面（2 状態の混合分布、継続確率と平均継続日数）、極端な変動の連鎖、Student-t の自由度（裾の厚さ）、
    前日高値・安値のブレイク確率、日中の高値・安値がつく時間帯

## トレードルール探索（`rules`）

値幅を取るためのルールを大量に試し、**偶然うまくいっただけのルールを厳しく除外**します。

```bash
python -m xauforecast rules --spread 0.30 --slip 0.10
```

`--spread` は往復スプレッド（$/oz）、`--slip` はストップ約定時のスリッページです。お使いの口座に合わせてください。
結果は `reports/rules.md`（要約）、`reports/rules.csv`（全ルールの成績）、`reports/rules_walkforward.csv` に出力されます。

試すルール（約 2,300 個のパラメータ組み合わせ）:

| 群 | 内容 |
|---|---|
| A レンジブレイク | アジア、アジア後半、ロンドン序盤 30 分、ロンドン→NY、COMEX 開場 15/30 分、NY 株開場 30 分、指標前 30 分のレンジを抜けた方向に入る。損切・利確はレンジ幅の倍数、レンジが狭い日だけ / 広い日だけ、の条件も |
| B 時刻イベント | 8:30、10:00、14:00、8:20、9:30、3:00、20:00、18:00 の初動 1/5/15 分に順張り / 逆張り（雇用統計日のみ、も） |
| C 時間帯保有 | NY 時間の a 時に買い（売り）、b 時に決済。全組み合わせ |
| D 平均回帰 | 当日始値 / VWAP から k×ATR 乖離したら逆張り |
| E 前日高安ブレイク | 前日高値・安値を抜けた方向に入る |
| F ギャップ埋め | 週明け（または全日）の窓を埋める方向に入る |
| G〜I 時間足 | 時系列モメンタム、ドンチャン、RSI（逆張り / 順張り） |
| J セッション順張り / 逆張り | アジア・ロンドンなどの方向に、次の時間帯で順張り / 逆張り（日中モメンタム）。前日終値→8:50 の方向で引け前 30 分を取る、も |
| K ロンドン・フィキシング | AM（10:30）/ PM（15:00）フィックスの前後 5〜30 分の売り / 買い、「ロンドン始値→PM フィックス」「アジア開始→ロンドン 8:00」など、研究で報告された時間帯（ロンドン時間で、夏時間のずれも日ごとに反映） |
| L FOMC | 政策決定日の 14:00 発表の初動に順張り / 逆張り、発表前のドリフト。FOMC の日程は組み込み（2024〜2026 年） |

過剰最適化の対策:

1. **期間分割**: 前半 60% で探索し、後半 40% は検証専用に残します。
2. **多重検定の補正**: 何千個も試すと、優位性がなくても最良ルールの t 値は 3 を超えます。全ルールの最大 t 値の分布を
   ブートストラップで求め（White の Reality Check / Romano-Wolf）、それを織り込んだ p 値で判定します。
   デフレート・シャープレシオも出します。
3. **前進型の選択**: 「毎月、直近 6 か月で最良だったルールに乗り換える」という探索の手順そのものの成績を出します。
   これがマイナスなら、探索で見つかるルールは偶然の産物です。
4. **コスト**: スプレッドとスリッページを差し引きます。スプレッドは時間帯で変え、再開直後（18:00〜19:00 NY）は 4 倍、
   8:30 の指標直後は 3 倍、10:00 / 14:00 直後と引け前は 2 倍にします。同じ足で損切と利確の両方に届いた場合は、損切が先と仮定します。
5. **年別の成績**: 上位ルールの 1 回あたり損益を年ごとに出し、特定の年だけで稼いでいないかを確認します。

どのルールを優先して確かめるべきかの参考に、金の日中の値動きに関する既存研究を [docs/research.md](docs/research.md) に
まとめました（ロンドン・フィキシング前後の下落、FOMC への反応の持続、日中モメンタム、曜日・月の効果など。出典つき）。

採用の条件は、補正後の p < 0.05、かつ検証期間でも平均がプラスで t > 1.65 であることです。

### 探索エンジンの検証（合成データ）

優位性がないデータで何も見つけないこと（偽陽性）と、既知の優位性を埋め込んだデータでそれを見つけること（検出力）を
確認しました。埋め込んだのは「アジア時間の方向に、ロンドン序盤 2 時間が少し続く」という優位性で、データは約 1.2 年分です。

| 埋め込んだ優位性 | 1 回あたりの純利益 | 結果 |
|---|---|---|
| なし | — | 2,266 ルール中、採用 **0 個**（群 K を加えた 2,336 ルールでも 0 個）。月次で乗り換える運用は t = −0.81（負け） |
| 小（0.02σ/分） | 約 $1 | 正しいルールが IS で **1 位**（t = 3.3）。ただし補正後 p = 0.29 で不採用 |
| 中（0.05σ/分） | 約 $3 | 正しいルールとその変形だけを採用（検証期間 t = 5.2）。月次で乗り換える運用も t = 6.5 |

約 1 年分のデータで多数のルールを試す場合、1 回あたり約 $1 の優位性は偶然と区別できません。小さな優位性を検出するには、
より長い期間（数年分の 1 分足）が必要です。Dukascopy なら 2003 年以降のデータを取得できます。
`fetch --start 2018-01-01` で取得し、`rules --max-days 3000` で長期間を使ってください。FOMC（年 8 回）のように回数の
少ないイベントは、探索期間に 30 回以上の取引が必要なため、数年分のデータで初めて評価されます。

## 予測に使う統計量（特徴量 約 140 個）

統計レポートの内容は、予測の時点ごとに計算し直す特徴量としてモデルに入ります。

| 分類 | 内容 |
|---|---|
| リターン | 過去 1分〜5日の 15 時間軸の正規化リターン |
| ボラ | 脱季節化した実現分散（5分〜21日）、ボラ比率、Parkinson レンジボラ、レンジボラと実現ボラの比、下方セミ分散の比率、ジャンプ比率（バイパワー変動）、実現歪度・尖度、最大 1 分変動、ボラのボラ |
| 季節性 | 現在と今後 15分〜24時間の季節的ボラ、時刻・曜日（周期）、月末月初、取引日内の経過時間、金曜 |
| イベント | 米指標 8:30 / 10:00、FOMC 等 14:00、COMEX 開場と終了、NY 株開場、ロンドン AM/PM フィキシング、東京 9:00 までの近さとそこからの経過、雇用統計日、指定した指標カレンダー（`--events`） |
| テクニカル | EMA 乖離（15分〜5日）と傾き、RSI（6 期間）、ボリンジャー z、ストキャスティクス、MACD（15分・1時間）、効率比（トレンド度）、1 分リターンの自己相関、分散比、連続同方向本数 |
| 価格構造 | 当日レンジ内の位置、当日・前日・週の高値/安値/始値/終値からの距離、ロンドン・NY 始値からの距離、週明けギャップ、$10/$50/$100 のキリ番からの距離 |
| 出来高 | 相対出来高、季節調整出来高、当日 VWAP からの乖離、売買の偏り（符号付き出来高） |

`fit` / `all` を実行すると、`features.md` と `feature_ic.csv` が出力されます。全特徴量について、ホライズン別に
将来リターンとの順位相関（IC）と t 値が載っており、どの統計量が実際に効いているかを確認できます。

## 予測モデルの仕組み

```
予測分散 σ²(t→t+h) = L̂_h(t) × Σ_{k=1..h} f(t+k)
```

- **f: 日中季節性プロファイル**。NY 時間の「週内の分」ごと（10080 スロット）に推定します。夏時間は自動で処理し、
  週末と日次休場は 0 になります。指標発表時刻のボラ急増もここで捉えます。
- **L̂_h: ボラ水準**。まずホライズンごとに HAR 回帰（過去 15分〜21日の脱季節化実現分散と非対称項）で予測し、
  その残差を全特徴量の勾配ブースティングで補正します。補正は、前進型の検証で誤差が減ったホライズンだけで使います。
- **平均（方向）**: 次の 4 つの予測器を組み合わせます。
  - 線形（リッジ、全特徴量）
  - 勾配ブースティング（全特徴量）
  - 類似局面（主要 28 個の統計量が現在と最も似ている過去 150 局面の、その後の値動き）
  - 時間帯統計（週内の時間帯ごとの平均リターン）

  それぞれを前進型の検証（各期間を、それより前のデータだけで学習したモデルで予測。ラベル期間の重なりは除外）で
  評価し、t > 3 のものだけを非負最小二乗で重み付けして合成します。有意なものがなければドリフト 0 です。
- **分布**: 前進型の検証で得た標準化残差の経験分布（Filtered Historical Simulation）を使い、ボラ局面（低・中・高）ごとに
  分けています。ファットテールと歪みをそのまま反映します。
- **経路**: 1 分ショックとバー内のヒゲをブロック・ブートストラップするモンテカルロ（既定 3000 本）です。
  ボラ水準の不確実性も含め、予想高値・安値、到達確率、どちらが先に到達するかを計算します。
- **時計時間で計算**します。「24 時間後」が週末をまたぐ場合も、取引のない時間は動かない前提で正しく扱います。
- **予測の根拠**も出力します。HAR のボラと補正後のボラ、方向の各予測器の寄与（$）、現在の各統計量が過去の分布の
  どこにあるか（分位）とその予測力、最も似た過去の局面とその後の値動きです。

## 検証結果（合成データの例）

この開発環境からは外部の相場データにアクセスできなかったため、金の 1 分足の性質を模した合成データで
パイプライン全体を検証しています。合成データの性質は、ボラのクラスタリング（時間単位と、数日続く局面）、日中季節性、指標スパイク、
週末ギャップ、ファットテール、ビッド・アスクの揺らぎです。**実データでの数値は、`python -m xauforecast all`
を実行して `reports/backtest.md` で確認してください。**

| 先 | 50%区間 | 90%区間 | 98%区間 | ボラ予測の改善（HAR のみ → 全特徴量） | 分位点損失の改善 | 方向 Brier の改善 |
|---|---|---|---|---|---|---|
| 1分 | 50.4% | 89.6% | 97.7% | 12.4% → 13.9% | 5.1% | +1.47% |
| 15分 | 48.5% | 88.8% | 97.6% | 60.1% → 68.8% | 9.5% | −0.03% |
| 1時間 | 48.1% | 89.1% | 97.7% | 72.1% → 82.4% | 10.4% | −0.18% |
| 4時間 | 50.1% | 89.2% | 97.5% | 74.0% → 81.7% | 9.2% | −0.28% |
| 24時間 | 50.7% | 86.5% | 96.2% | 71.8% → 72.1% | 7.6% | −0.61% |

- 「ボラ予測の改善」は、無条件のボラ（期間全体の平均）で予測した場合と比べて、QLIKE 損失が何 % 減ったかです。
  全特徴量の勾配ブースティングによる補正で、15分〜8時間のボラ予測がさらに 4〜10 ポイント改善しました。
- 価格到達確率の較正例: 1時間以内に ±0.25% へ到達する予測 20.2% に対して実際 20.9%、
  24時間以内に ±0.5% は予測 57.9% に対して実際 54.9%。
- 方向は 1分（的中率 55%）と 5分（52%）だけ予測力があり、合成データに入れたビッド・アスクの揺らぎに由来します。
  15分以上は、多数の統計量を使っても予測できません（合成データは方向がランダムになるよう作っているので、これが正しい結果です）。
- ボラ局面は数日続くため、検証期間 6 か月の独立なサンプルは多くありません。区間のカバー率は期間によって数ポイント揺れます。

## 注意事項

- 本ツールは統計的な分析と確率予測を行うもので、利益を保証するものではありません。投資判断は自己責任で行ってください。
- 戦争、中央銀行の介入、要人発言などの突発的な事象は、過去の統計の範囲を超えることがあります。
- 指標発表日の正確な分析には、`--events` でカレンダーを指定してください（雇用統計の自動推定は近似です）。
- Dukascopy のデータは遅れて公開されます。秒単位のリアルタイム性が必要な場合は MT5 を使ってください。
