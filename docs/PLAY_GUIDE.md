# 剣は「クラフト」するな、「鍛て」ろ。<br>本格剣鍛冶MOD『Real Swordsmithing』遊び方ガイド

クラフトテーブルに鉄インゴット2個と棒1本。カチッ。はい、剣のできあがり——。

Minecraftを遊んだことがあるなら、誰もが何百回とやってきた操作です。でも、現実の刀鍛冶がこれを見たら卒倒するでしょう。本物の剣は、**炉の火を操り、鋼を打ち、水で焼き入れ、砥石で研いで**、ようやく一振りが生まれるもの。

『Real Swordsmithing(本格剣鍛冶MOD)』は、その工程をまるごとMinecraftに持ち込んだMODです。このMODの「鍛造鋼の剣」には**クラフトレシピが存在しません**。手に入れる方法はただひとつ、あなた自身が鍛冶場に立つことだけです。

この記事では、導入から初めての一振りが完成するまでを、順を追って解説します。

---

## このMODは何が違うのか

ふつうの「加工に時間がかかるだけ」のMODと違い、このMODの主役は**温度**です。

- 金属はニュートンの冷却法則に従って**実時間で冷めていきます**。炉から出した瞬間から勝負です。
- 温度は摂氏で管理され、**約720℃を下回った鋼はハンマーで叩いてもビクともしません**。
- 焼き入れは780〜950℃の一瞬を見極める作業。熱しすぎた刀身は**「バキッ」と音を立てて割れます**。
- 150℃を超えた金属を素手で持てば**火傷します**(→やっとこを使いましょう)。
- そして完成した剣の**攻撃力は、あなたの腕前で変わります**(6.6〜8.5)。同じ手順でも、丁寧に打った剣とそうでない剣は別物になります。

失敗はありますが、理不尽ではありません。割れた刀身は打ち直せますし、工程のヒントはアイテムのツールチップ・GUI・進捗ツリーが常に教えてくれます。

## 鍛冶場を建てよう

4つの設備を近くに並べて置きます。おすすめは**炉と金床を隣接**させる配置。鍛造中は炉と金床を何往復もするので、動線の短さがそのまま剣の出来につながります(金属は歩いている間にも冷めます)。焼き入れ樽には水入りバケツで水を張っておきましょう。**一度張った水はなくならない**ので補充は不要です。

## 基本のき:温度との付き合い方

このMODの攻略は、つまるところ温度管理です。最初に3つだけ覚えてください。

1. **温度は色で分かる。** 常温→黒熱→暗赤熱(720℃〜)→赤熱(780〜950℃)→橙熱→黄熱(1150℃〜)→白熱(〜1280℃)。加工品は見た目も発光も変わります。
2. **熱い金属を手に持つと、ホットバー右上に温度ゲージ(HUD)が出ます。** ゲージには鍛造720℃・焼き入れ780〜950℃の目盛りが刻んであるので、数字を暗記しなくても戦えます。ツールチップにも正確な温度と状態が出ます。
3. **150℃以上の金属は素手で持たない。** 継続ダメージを受けます。**鍛冶やっとこをメインハンドかオフハンドに持っていれば無効**(代わりにやっとこの耐久が減ります)。オフハンドにやっとこを常備するのが鍛冶屋の正装です。

## 炉の火を操る

鍛冶炉は「置いて放置」の設備ではありません。火加減そのものがゲームプレイです。

1. **燃料をくべる** — 木炭か石炭を持って炉を右クリック。1個=60秒ぶん、最大300秒までストックできます。
2. **点火する** — 火打石と打ち金で右クリック。
3. **火加減はふいごで** — 点火直後の炉は送風なしの**熾火(おきび)で約300℃**に安定します。**手ふいご**で右クリックすると風が送られ、吹くほど火力が上がって**最大約1280℃**に。送風は時間とともに衰えるので、高温を保ちたければ数秒おきに吹き続けます。この「シュコー、シュコー」が鍛冶の呼吸です。
4. **GUIで状態を見る** — 素手で炉を右クリックすると画面が開きます。
   - **温度計**:焼き戻し(水色)・鍛造(金)・焼き入れ(赤)・製錬(黄)の適温帯が色分けされ、炉の火の温度が下から満ちていきます。中の加工品の温度は白いマーカーで表示。カーソルを合わせれば温度早見ツールチップが出ます。
   - **炎ゲージ**:燃料の残り。 **送風バー**:ふいごの効き。 **進行矢印**:製錬・焼き戻しの進み具合。
   - 材料の出し入れはスロット経由でもOK。ただし熱い材料を素手でつかめば当然火傷します。やっとこを持って炉を直接右クリックすれば、安全に取り出せます。

火加減の使い分けはこれだけです:**強火(ふいご全開)=製錬と鍛造の加熱、弱火(熾火・放置)=焼き戻し**。

## 実践:一振りの剣ができるまで

ここからが本番です。全工程はこう流れます。

```
鉄の原石 → 製錬 → 海綿鉄の塊 → 鍛造(8打) → 鋼片(ビレット)
→ 鍛造(10打) → 打ち延ばした鋼材 → 鍛造(12打) → 荒打ちの刀身
→ 焼き入れ → 焼き入れした刀身 → 焼き戻し → 焼き戻しした刀身
→ 研ぎ(24回) → 研ぎ上げた刀身 → 柄付け → ⚔ 鍛造鋼の剣
```

### 工程1:製錬 ——「たたらの火」

**鉄の原石**を持って炉を右クリックして投入。**1150℃以上(黄熱)を30秒**保つと「海綿鉄の塊」になります。

1150℃は放っておいて出る温度ではありません。ふいごを数秒おきに吹き続けて火力を維持します。まさに、たたら吹き。GUIの進行矢印で進み具合が見えますが、火を落として**700℃を下回ると進行は失われていく**ので、席を外すのは禁物です。

### 工程2:鍛造 —— 30打の対話

海綿鉄の塊を **720℃以上** に熱したら、やっとこを構えて炉から取り出し、金床に置きます(持って右クリック)。あとは**鍛冶ハンマーで右クリック**して打つ、打つ、打つ。

- **海綿鉄の塊 → 8打 → 鋼片(ビレット)**(不純物のノロを絞り出す)
- **鋼片 → 10打 → 打ち延ばした鋼材**(棒状に延ばす)
- **鋼材 → 12打 → 荒打ちの刀身**(切先・刃・茎の形を打ち出す)

ここで、このMODで一番大事なテクニックを教えます。

> **「会心の一打」— 900〜1150℃(橙〜黄熱)で打った一打は、剣の出来栄えに直接加点されます。**

打つたびにメッセージが出ますが、適温で打てたときだけ**「会心の一打!」**に変わり、火花も派手になります。逆に720℃ギリギリの鈍い一打は、出来栄えの平均点を静かに下げていきます。

金属は1打ごとに約12℃、置いているだけでも刻々と冷めます。つまり実際のリズムはこうなります:**炉で橙熱まで加熱 → 金床で4〜6打 → 温度が900℃を切ったら炉へ戻す → 再加熱 → また打つ**。この往復こそが鍛冶です。「熱いうちに打て」ということわざを、身体で理解できます。

### 工程3:焼き入れ —— 一瞬の見極め

荒打ちの刀身ができたら、いよいよ最大の山場です。刀身を**780〜950℃(赤熱)**に熱し、水を張った焼き入れ樽に右クリックで浸けます。

- **950℃超** → 「バキッ」。急冷の衝撃で**ひび割れた刀身**に…(後述のリカバリーで復活可能)
- **780℃未満** → 焼きが入らず不発。熱し直してやり直し
- **適温** → 「ジュウッ…!」**焼き入れした刀身**の完成

そして上級者向けの真実をひとつ。**理想温度は865℃**です。焼き入れの質は865℃にどれだけ近かったかで採点され、剣の攻撃力の35%を占めます。HUDゲージの780と950の目盛りのちょうど中間よりやや下——赤熱の中でも「深い赤」を狙ってください。炉から出した刀身が冷めていく数秒間、HUDを見つめて865℃前後で「今だ!」と浸ける。この緊張感はこのMODでしか味わえません。

### 工程4:焼き戻し —— 熾火の辛抱

焼き入れした刀身は硬いものの、ガラスのように脆い状態です。粘りを与えるため低温でじっくり熱を入れ直します。

**ふいごを吹いていない熾火の炉(約300℃)**に刀身を入れ、**150〜400℃で20秒**キープすると「焼き戻しした刀身」になります。GUIの矢印が進行を教えてくれます。

ここでの禁忌はただひとつ:**絶対にふいごを吹かないこと**。**460℃を超えた瞬間、焼きが完全に失われて荒打ちの刀身に逆戻り**します(焼き入れからやり直し)。強火の工程が続いた後なので、つい癖でふいごに手が伸びる——このMOD屈指の事故ポイントです。

### 工程5:研ぎ —— 刃が立つ

焼き戻しした刀身が**冷えるのを待って**(常温〜60℃)、手に持って研ぎ台を**右クリック×24回**。シャッ、シャッと研ぎ進み、ツールチップで進行(研ぎ進行: n / 24)が確認できます。

熱いまま研ごうとすると「焼きが戻ってしまう」と職人に止められます。急がば冷やせ。

### 工程6:柄付け —— 世界に一振り

研ぎ上げた刀身を金床に置き、部品を持って右クリックで組み付けます。順番は現実の剣と同じ、茎に通す順です。

1. **剣の鍔**(手を守るガード)
2. **剣の柄**(革巻きのグリップ)
3. **剣の柄頭**(柄尻の重り)
4. 最後に**ハンマーで3打**、柄頭をかしめて固定
5. 素手で右クリックして、**鍛造鋼の剣**を手に取る

金床の上に部品が積み上がっていく様子は3D描画で見えます。最後の一打の音を聞いた瞬間の達成感は、クラフトテーブルの「カチッ」とは比べものになりません。

## あなたの剣は何点?——出来栄えと攻撃力

完成した剣のツールチップには**出来栄え(%)と等級**が刻まれます。内訳は:

- **鍛えの質(65%)** — 全打撃(30打+打ち直し分)のうち「会心の一打」だった割合
- **焼き入れの質(35%)** — 焼き入れ温度が理想865℃にどれだけ近かったか

| 出来栄え | 等級 | 攻撃力の目安 |
|---|---|---|
| 〜59% | 並(灰) | 〜6.9 |
| 60〜71% | 良(緑) | 〜7.4 |
| 72〜83% | 上作(水色) | 〜7.8 |
| 84〜94% | 傑作(紫) | 〜8.3 |
| 95%〜 | 神業(金) | 〜8.5 |

参考までに、バニラのダイヤの剣は攻撃力8。つまり**「傑作」以上を打てる鍛冶屋になれば、鉄素材からダイヤ超えの剣が生まれます**。ちなみに攻撃速度1.8はバニラの剣(1.6)より軽快、耐久は780、エンチャント性14。金床に研ぎ上げた刀身を合わせれば修理もできます。

工程の途中でも刀身のツールチップに「鍛えの質」「焼き入れの質」が随時表示されるので、自分の腕の上達が数字で見えます。1本目で「並」を打ち、5本目で「傑作」が出たときの成長実感は本物です。

## 失敗図鑑とリカバリー

| 失敗 | 原因 | リカバリー |
|---|---|---|
| 刀身が割れた | 950℃超で焼き入れ | **熱して金床で6打**すれば荒打ちの刀身に復活。それまでの鍛えの履歴は引き継がれるので挽回可能 |
| 刀身がなまった | 焼き入れ済みの刀身を460℃超に加熱 | 荒打ちに戻るだけ。焼き入れからやり直し |
| 焼きが入らない | 780℃未満で浸けた | 熱し直して再チャレンジ |
| 火傷する | 150℃以上を素手で保持 | やっとこを持つ(オフハンド常備を推奨) |
| 叩いても反応しない | 720℃未満に冷えた | 炉で暗赤熱以上に熱し直す |
| 製錬が進まない | 火力不足(1150℃未満) | ふいごを数秒おきに吹き続ける |

「音で学ぶ」という隠し進捗があります。取り方は……刀身が割れたときのお楽しみ。**失敗も修行のうち**、というわけです。

## 上達のコツ10選

1. **オフハンドにやっとこ。** これだけで火傷とは無縁になります。
2. **炉と金床は隣接配置。** 移動時間=冷却時間です。
3. **鍛造の加熱は「橙熱の上のほう」まで。** 900℃ちょうどで出すと数打で会心ゾーンを割ります。1000℃前後で出せば会心の一打を多く稼げます(1150℃超で打つと逆に外れるので欲張りは禁物)。
4. **打つ前にHUDを見る癖を。** 「今この一打は会心か?」を確認してから振ると平均点が伸びます。
5. **焼き入れは炉の前で待ち構えない。** 刀身を持って樽の前に立ち、HUDで865℃を狙い撃ちしましょう。
6. **焼き戻し前にふいごの余熱に注意。** 送風の勢いが残った炉は300℃を大きく超えています。送風バーが空になり、温度計が落ち着いてから刀身を入れること。
7. **燃料は常に満タンに。** 製錬中の燃料切れは進行ロスに直結します。
8. **失敗した刀身も捨てない。** 鍛えの履歴は割れても引き継がれます。打ち直しの6打を会心で揃えれば、むしろ点は伸びます。
9. **2本目からが本番。** 1本目は工程を覚える授業料。等級「神業」は、865℃ジャストの焼き入れと9割超の会心率が要求される職人の領域です。
10. **進捗ツリーを開こう。** 「鍛冶のはじまり」から「世界に一振り」まで、迷ったときのチェックリストになります。

## おわりに

このMODの剣は、性能だけ見れば「ちょっと強い鉄の剣」かもしれません。でも、炉の前でふいごを吹き、865℃の一瞬に息を止め、最後のかしめを打ち終えたあなたにとって、その一振りは間違いなく**世界に一振りの剣**です。

腰を据えて、いい剣を打ってください。良い鍛冶ライフを!
